Политика конфиденциальности приложения «Слова из Букв: Головоломки»

Эта страница описывает, какие данные собираются при использовании мобильного приложения «Слова из Букв: Головоломки» (далее — «Приложение») и как они обрабатываются.

Кто разработчик

Приложение разработано индивидуальным разработчиком (далее — «Разработчик»). Связь: terekhsupport@atomicmail.io.

Какие данные собирает само Приложение

Никаких персональных данных Приложение не собирает и не передаёт.

Внутри устройства Приложение хранит только локальный игровой прогресс (localStorage WebView): пройденные уровни, настройки звука/вибрации, статистика. Эти данные:

  • хранятся только на устройстве пользователя;
  • не передаются ни Разработчику, ни третьим лицам;
  • удаляются при удалении приложения (Android system reset);
  • могут быть очищены пользователем через системные настройки приложения.

Какие данные собирают встроенные сервисы

Приложение использует Yandex Mobile Ads SDK (рекламная сеть Яндекса) для показа межстраничной и вознаграждаемой рекламы. SDK работает по своей политике конфиденциальности и может собирать следующие данные с устройства пользователя:

  • Идентификатор рекламы Android (Android Advertising ID) — для отслеживания эффективности рекламных кампаний и предотвращения повторных показов.
  • IP-адрес — для геотаргетинга рекламы и определения региона.
  • Информация об устройстве — модель, версия Android, язык системы, разрешение экрана.
  • Информация о взаимодействии с рекламой — показы (impressions), клики, длительность просмотра.

Эти данные передаются на серверы ООО «Яндекс» и обрабатываются согласно политике Яндекса:

  • Политика конфиденциальности Яндекса
  • Политика обработки данных в Yandex Mobile Ads

Аналитика (Yandex AppMetrica)

Приложение использует SDK Yandex AppMetrica для сбора обезличенной аналитики поведения пользователей:

  • Уникальный идентификатор устройства (UUID, генерируется приложением, не связан с личными данными и не используется вне аналитики).
  • События использования: запуски, прохождение уровней, использование подсказок, просмотр рекламы, открытие настроек, нахождение слов.
  • Технические данные: версия приложения, версия Android, модель устройства, разрешение экрана.
  • Часовой пояс, язык, страна (по IP-адресу, IP-адрес не сохраняется).
  • Crash-репорты: при сбое приложения отправляется stack trace для диагностики.

Данные передаются на серверы ООО «Яндекс» (территория РФ) и используются для:

  • анализа поведения пользователей и улучшения приложения;
  • подсчёта аудитории, ретеншена, конверсии;
  • выявления ошибок и сбоев приложения.

Персональные данные (имя, email, номер телефона, точная геолокация) не собираются.

Подробнее: Политика конфиденциальности Yandex AppMetrica.

Push-уведомления (локальные)

Приложение показывает локальные push-уведомления (напоминания о возврате в игру). Реализованы через Android AlarmManager локально на устройстве — никаких токенов или серверов рассылок не используется. Можно отключить в системных настройках Android (Приложения → «Слова из Букв» → Уведомления).

Возрастные ограничения

Приложение предназначено для всех возрастов (категория 0+). Yandex Mobile Ads SDK может ограничивать тип показываемой рекламы для несовершеннолетних в соответствии с законодательством РФ.

Права пользователя

Пользователь имеет право:

  • Отключить персонализированную рекламу: настройки Android → Реклама → «Сброс рекламного идентификатора» / «Не персонализировать рекламу».
  • Удалить локальные данные: настройки Android → Приложения → «Слова из Букв: Головоломки» → Хранилище → «Очистить данные», либо просто удалить приложение.
  • Связаться с Разработчиком по любым вопросам: terekhsupport@atomicmail.io.

Cookies, серверный обмен

Приложение не использует:

  • Cookies (WebView хранит только localStorage внутри приложения).
  • Сторонние сервисы аналитики (Google Analytics, Firebase Analytics и т.п. — кроме описанной выше Yandex AppMetrica).
  • Собственный backend / API (все данные обрабатываются на устройстве или передаются напрямую в SDK Яндекса).
  • Авторизацию через email, телефон, соцсети.
  • Серверные push-уведомления (FCM, VK Push). Push-уведомления приложения — только локальные, см. раздел выше.
  • Точную геолокацию (GPS). Используется только страна по IP (Yandex Mobile Ads + AppMetrica).

Изменения политики

Разработчик может обновить эту политику. Существенные изменения будут сопровождаться повышением версии приложения в магазине и публикацией новой версии этого файла в облачном хранилище (URL остаётся прежним).
